│     Models      │    │   ViewModels    │    │     Views       │
│                 │    │                 │    │                 │
│ • DoList        │◄───┤ • ListsViewModel│◄───┤ • ListsView     │
│ • Task          │    │ • TasksViewModel│    │ • TasksView     │
